Transformation-aware behavioural attestation for derived open-weight model artifacts. Every number on this page was produced by the committed code.

Signing proves the bytes didn't change. Nothing proves the behaviour didn't.
An organisation verifies the model it downloads, then quantizes it to fit the serving budget — and at that moment the signature is void and nothing checks that behaviour survived. This is that check.

3 · Why a significant deviation correctly did not fire

Every statistic here is a ratio against the audited artifact's own level, so thresholds are relative to the derivation rather than one global constant. This artifact's level is 0.4554 against an honest range of 0.244–0.295 — statistically significant (plevel = 4.76e-04) but only 1.546× the honest maximum, short of the 2× materiality guard. A modification pervasive enough to raise its own baseline hides itself from ratio-normalised tests. That is a real limitation of the method, and it is why a second, non-ratio channel exists.

4 · The component channel — provenance, not behaviour

Calibrated on 6 honest derivations of the declared family, each of which modifies exactly 210 of the model's tensors — with no variance at all. 62 tensor groups are modified by no honest derivation.

The audited artifact modifies 272 tensors and trips 62 of those groups. Composition: the token embedding, the final norm, and every layernorm — exactly the set the honest quantizer skips, because it only touches 2-D tensors and skips embed/lm_head/norm by name. The separation is structural, not a matter of magnitudes.

How this must be read. The honest null for a never-touched group is degenerate — identically zero, no variance — so no p-value is computed and none is claimed. The correct statement is: this artifact modifies N tensor groups that none of the K honest derivations of its declared family modifies. It is evidence of provenance outside the declared transformation, not proof of a backdoor: a benign full fine-tune would flag identically.

7 · Limitations

  • Quantization here is simulated round-to-nearest, not a bitsandbytes/GPTQ/GGUF kernel; the set of tensor groups an honest derivation skips is a property of that implementation.
  • The component channel has a degenerate (identically zero) null — it is a component-level finding with the number of honest derivations stated, never a p-value.
  • It detects provenance deviation, not malice: a benign full fine-tune flags identically.
  • It needs full weights on both sides, so it does not apply to adapter-only bundles.
  • An attacker who confines a change to the tensor groups the honest transformation already touches produces no anomaly in that channel.
  • Ratio-normalised behavioural statistics can be self-masking (section 3).
  • Finite probing cannot exclude rare triggers outside the exercised distribution; a compromised reference is faithfully preserved by an honest derivation.
  • One model family at one size (135M), CPU only. No claim of generality across scales.
